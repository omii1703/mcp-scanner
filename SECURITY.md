# Security Policy

## Reporting a Vulnerability

If you identify a security vulnerability within AgentShield itself (rather than a finding AgentShield produces about another scanned codebase), please report it to us privately to ensure a coordinated disclosure path.

**Please do not open public GitHub issues for security vulnerabilities in AgentShield.**

Instead, please send security reports via:
- Email: **security@agentshield.org**

Please include the following information in your report:
- A clear description of the vulnerability and its potential impact
- Detailed step-by-step reproduction instructions or a Proof of Concept (PoC) script
- Any potential mitigations or fixes you recommend

We aim to acknowledge all security reports within 48 hours and work diligently to release a patch or advisory in a timely manner.

Thank you for helping keep AgentShield safe!
